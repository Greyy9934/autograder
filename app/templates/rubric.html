GRADING RUBRIC
System Evaluation criteria

Independent evaluation dimensions

Each dimension is assessed separately. Missing evidence must remain missing; uncertain results must not be presented as facts.

  • Correctness — agreement with the approved specification and verified test evidence.
  • Compilation and syntax — compiler diagnostics and language-level issues.
  • Memory safety — pointer use, bounds, allocation and lifetime risks.
  • Time complexity — theoretical analysis supported by empirical measurements.
  • Space complexity — auxiliary memory use and growth behaviour.
  • Mathematical correctness — proof quality, invariants and counterexamples.
  • Code quality — readability, modularity and maintainability.
  • Originality signals — similarity indicators for investigation, never automatic proof of plagiarism.
